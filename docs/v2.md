# AAC v2 field test

AAC v2 is a separate, early-stage consulting framework for establishing a sound project foundation and a bounded first-MVP brief. It does not replace the current AAC or its schema.

[Open the AAC v2 field test](https://aac.slolab.ai/v2/){ .md-button .md-button--primary }

## What it is for

An AI engineering facilitator and a client team use one shared overview during a discovery conversation. The canvas covers:

1. Work today
2. Change
3. Solutions
4. Development reality
5. Value and evidence
6. MVP

The opening section establishes a concise project description, named users, a recent real case, and an evidenced baseline. The wider canvas records the desired change and trade-offs, prior attempts and candidate solutions, user-provided biomedical and public-sector constraints, accountable changes, decision-grade metrics, and a bounded MVP with user stories and an explicit user–developer collaboration setup.

Each section has an information control. Hovering gives a short decision-relevant cue; opening it shows deeper facilitator guidance without adding instructions to the canvas itself.

## Deliberately lightweight

AAC v2 has no completion score, confidence states, required answer order, validation errors, or automated gap management. Questions may remain unanswered. Missing answers are useful signals during discovery and never block export.

The route saves the current draft in the browser. **Start fresh** clears that draft after confirmation.

## RO-Crate portability

Any partial or completed v2 canvas can be exported as an RO-Crate ZIP. The package contains:

- `project-foundation.md` — the human-readable conversation result
- `aac-v2.json` — the v2 canvas data used to reopen the work
- `ro-crate-metadata.json` — RO-Crate 1.2 metadata
- `README.md` — a short package guide

Use **Reopen** on the v2 route to continue from a v2 RO-Crate. V1 imports and v1-to-v2 conversion are intentionally unsupported.
